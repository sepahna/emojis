۱) دانلود و انتخاب فایل

از جستجو، فیلتر مجموعه و مرتب‌سازی استفاده کن. در هر صفحه فقط ۲۰ ایموجی رندر می‌شوند تا از لگ و مصرف RAM جلوگیری شود. دکمه «دانلود» فایل JSON را ذخیره می‌کند، «JSON» آن را در تب جدید باز می‌کند و «کپی مسیر» مسیر فایل را کپی می‌کند.

این روش برای HTML ساده، PHP، وردپرس، Django، Laravel، React و تقریباً هر سایت دیگری مناسب است. فایل JSON از GitHub Pages دریافت می‌شود؛ فقط اینترنت بازدیدکننده باید به آن دسترسی داشته باشد.

۳) تست آنلاین و تنظیم اندازه ایموجی

اندازه را با کشیدن نوار تغییر بده؛ پیش‌نمایش زنده به‌روزرسانی می‌شود و کد آماده نیز بر اساس اندازه انتخابی ساخته می‌شود. کد را کپی و در پروژه خودت استفاده کن.

۳) استفاده روی هاست اشتراکی (cPanel / DirectAdmin)
اگر می‌خواهی فایل‌ها از هاست خودت بارگذاری شوند، این کار نیاز به Python یا Node ندارد:
  1. در File Manager هاست، وارد public_html شو.
  2. یک پوشه به نام emojis بساز.
  3. JSONهای موردنیاز را دانلود و در public_html/emojis/ آپلود کن.
  4. در صفحه HTML یا PHP سایت، Lottie را از CDN اضافه کن و مسیر فایل را مطابق نمونه زیر قرار بده.
<script src="https://cdnjs.cloudflare.com/ajax/libs/lottie-web/5.12.2/lottie.min.js"></script>
<div id="emoji-host" style="width:120px;height:120px"></div>
<script>
lottie.loadAnimation({
  container: document.getElementById('emoji-host'),
  renderer: 'svg',
  loop: true,
  autoplay: true,
  path: '/emojis/Proxy_PJ2_140.json'
});
</script>
در این مثال، آدرس فایل باید در مرورگر باز شود: https://YOUR-DOMAIN.com/emojis/Proxy_PJ2_140.json. اگر فایل در پوشه دیگری است، مسیر path را مطابق محل واقعی تغییر بده. فایل JSON باید قابل دسترسی عمومی باشد.

۵) استفاده در سرور لینوکس (Nginx)
فایل JSON را در مسیر وب پروژه قرار بده؛ برای نمونه اگر ریشه سایت /var/www/example.com/public است، فایل را در /var/www/example.com/public/emojis/ قرار بده. Nginx فایل JSON را مانند فایل استاتیک سرو می‌کند؛ نیازی به اجرای Python برای نمایش انیمیشن نیست. سپس در کد صفحه از مسیر زیر استفاده کن:
path: '/emojis/Proxy_PJ2_140.json'
اگر فایل‌ها خارج از Document Root هستند، باید در تنظیمات Nginx یک مسیر استاتیک تعریف شود و پس از تغییر تنظیمات، Nginx reload شود. فایل‌ها را در مسیرهای خصوصی یا پوشه‌ای که دسترسی HTTP ندارد قرار نده.


۶) استفاده در React
ابتدا نصب کن: npm install lottie-web و سپس در کامپوننت:
import { useEffect, useRef } from 'react';
import lottie from 'lottie-web';

export default function AnimatedEmoji() {
  const ref = useRef(null);

  useEffect(() => {
    const animation = lottie.loadAnimation({
      container: ref.current,
      renderer: 'svg',
      loop: true,
      autoplay: true,
      path: 'https://sepahna.github.io/emojis/assets/Proxy_PJ2_140.json'
    });
    return () => animation.destroy();
  }, []);

  return <div ref={ref} style={{ width: 100, height: 100 }} />;
}


۷) دانلود JSON با Python
Python 3 و requests لازم است: python -m pip install requests.
import requests
import json

url = "https://sepahna.github.io/emojis/assets/Proxy_PJ2_140.json"
response = requests.get(url, timeout=30)
response.raise_for_status()
animation = response.json()

with open("emoji.json", "w", encoding="utf-8") as file:
    json.dump(animation, file, ensure_ascii=False, indent=2)

print("Saved:", animation.get("nm", "Lottie animation"))


۸) تبدیل TGS تلگرام به JSON با Python
فایل TGS معمولاً JSON فشرده با GZIP است. این کد آن را استخراج می‌کند:
import gzip
import json

with open("sticker.tgs", "rb") as file:
    data = gzip.decompress(file.read())

animation = json.loads(data.decode("utf-8"))
with open("sticker.json", "w", encoding="utf-8") as file:
    json.dump(animation, file, ensure_ascii=False, indent=2)

print("TGS converted to JSON")


۹) دانلود گروهی چند ایموجی با Python
from pathlib import Path
import requests

FILES = [
    "Proxy_PJ2_140.json",
    "Proxy_PJ7_067.json",
    "ApplicationEmoji_Mehran_001.json",
]

base = "https://sepahna.github.io/emojis/assets/"
out = Path("emojis")
out.mkdir(exist_ok=True)

for name in FILES:
    response = requests.get(base + name, timeout=30)
    response.raise_for_status()
    (out / name).write_bytes(response.content)
    print("Downloaded:", name)


نکته‌های مهم: فایل‌های JSON این کتابخانه Lottie هستند؛ برای نمایش در مرورگر از Lottie Web استفاده کن. مسیر فایل باید دقیق و با حروف بزرگ/کوچک درست باشد. برای استفاده روی هاست خودت، JSONها را آپلود کن و مسیر محلی را به path بده؛ برای استفاده مستقیم از کتابخانه، URL کامل GitHub Pages را قرار بده. فایل‌ها از طریق HTTP/HTTPS قابل دسترسی باشند و در مرورگر با خطای 404 مواجه نشوند.
