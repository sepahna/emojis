راهنمای کامل استفاده از ایموجی‌ها و کد Python

۱) دانلود فایل

روی «دانلود» هر کارت کلیک کن تا فایل JSON ذخیره شود. «JSON» فایل را در تب جدید باز می‌کند و «کپی مسیر» مسیر نسبی فایل را در کلیپ‌بورد کپی می‌کند. از جستجو، فیلتر مجموعه و مرتب‌سازی استفاده کن. در هر صفحه حداکثر ۲۰ ایموجی ساخته و انیمیشن می‌شود تا از لگ و مصرف زیاد RAM جلوگیری شود.

۲) استفاده در وب با Lottie

کتابخانه Lottie Web را اضافه کن، یک عنصر ظرف بساز و مسیر JSON را به آن بده:

<script src="https://cdnjs.cloudflare.com/ajax/libs/lottie-web/5.12.2/lottie.min.js"></script>
<div id="emoji" style="width:100px;height:100px"></div>
<script>
lottie.loadAnimation({
  container: document.getElementById('emoji'),
  renderer: 'svg',
  loop: true,
  autoplay: true,
  path: './assets/Proxy_PJ2_140.json'
});
</script>

۳) خواندن و ذخیره JSON با Python

این نمونه یک فایل JSON را از کتابخانه دانلود می‌کند و به‌عنوان فایل محلی ذخیره می‌کند. Python 3 و پکیج requests لازم است (نصب: python -m pip install requests):

import requests
import json

url = "https://sepahna.github.io/emojis/assets/Proxy_PJ2_140.json"

response = requests.get(url, timeout=30)
response.raise_for_status()

animation = response.json()  # تبدیل JSON به dict پایتون

with open("emoji.json", "w", encoding="utf-8") as file:
    json.dump(animation, file, ensure_ascii=False, indent=2)

print("دانلود و ذخیره شد:", animation.get("nm", "Lottie animation"))

۴) تبدیل فایل TGS تلگرام به JSON با Python

فایل TGS معمولاً JSON فشرده‌شده با GZIP است. این کد فایل TGS را باز کرده و JSON قابل استفاده را ذخیره می‌کند:

import gzip
import json

with open("sticker.tgs", "rb") as file:
    compressed = file.read()

data = gzip.decompress(compressed)
animation = json.loads(data.decode("utf-8"))

with open("sticker.json", "w", encoding="utf-8") as file:
    json.dump(animation, file, ensure_ascii=False, indent=2)

print("TGS به JSON تبدیل شد.")

۵) دانلود گروهی چند ایموجی با Python

اسم فایل‌ها را در لیست بگذار؛ اسکریپت آن‌ها را در پوشه emojis دانلود می‌کند:

from pathlib import Path
import requests

FILES = [
    "Proxy_PJ2_140.json",
    "Proxy_PJ7_067.json",
    "ApplicationEmoji_Meh​ran_001.json",
]

base = "https://sepahna.github.io/emojis/assets/"
out = Path("emojis")
out.mkdir(exist_ok=True)

for name in FILES:
    response = requests.get(base + name, timeout=30)
    response.raise_for_status()
    (out / name).write_bytes(response.content)
    print("Downloaded:", name)

نکته: نام فایل باید دقیقاً مطابق نام موجود در کتابخانه باشد. فایل‌های JSON این سایت Lottie هستند؛ برای نمایش در وب از Lottie Web استفاده کن.
